# Python Loops

A collection of Python practice programs focused on **`for` loops, `while` loops, and loop control statements**.

## 🚀 Concepts Covered

- `for` loops
- `while` loops
- `range()`
- Nested iteration
- `break`
- `continue`
- `pass`
- Counting and accumulation
- Searching and comparison logic
- Basic number problems

## 📝 Programs Practiced

Examples include:

- Displaying numbers
- Even and odd numbers
- Sum and average calculations
- Largest and smallest values
- Second largest and second smallest values
- Number frequency
- Prime number checking
- Fibonacci series
- Multiplication tables
- Powers
- Number guessing game

## 🧠 Learning Focus

The purpose of this repository is to strengthen **iteration, problem-solving, and logical thinking** by solving problems with loops.

## ▶️ How to Run

```bash
git clone https://github.com/abjaiyad/Python-Loops.git
cd Python-Loops
python filename.py
```

Replace `filename.py` with the program you want to run.
