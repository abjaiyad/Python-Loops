# Python Loops

A collection of **78 Python practice programs** built while learning and strengthening `for` loops, `while` loops, nested loops, loop control, number problems, and pattern printing.

The repository follows my progression from simple loop exercises to more challenging problems involving state tracking, digit manipulation, searching, analysis, and nested-loop patterns.

## 🚀 Concepts Covered

- `for` loops
- `while` loops
- Nested loops
- `range()`
- `break`, `continue`, and `pass`
- Counting and accumulation
- Running totals and statistics
- Searching and first-match logic
- Conditional filtering inside loops
- Digit extraction using `%` and `//`
- Number properties and classification
- Pattern printing
- Basic problem-solving and logical thinking

## ▶️ How to Run

Clone the repository and run any Python program:

```bash
git clone https://github.com/abjaiyad/Python-Loops.git
cd Python-Loops
python filename.py
```

Replace `filename.py` with the program you want to practice.
